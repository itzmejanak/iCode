Theme palettes used by iCode's theme variants (docs/design-and-navigation.md)

iCode takes these projects' published colour values: their palettes and terminal colours,
from the files named. No code is taken from them. Each is under the MIT licence below, with
its own copyright notice:

- Catppuccin Latte and Mocha: catppuccin/palette (palette.json, commit 07d02aa)
  Copyright (c) 2021 Catppuccin
- Dracula terminal colours: dracula/windows-terminal (dracula.json, commit 06f6371)
  Copyright (c) 2019 thismat
- Nord terminal colours: nordtheme/visual-studio-code (themes/nord-color-theme.json, commit 8ead098)
  Copyright (c) 2016-present Sven Greb <development@svengreb.de> (https://www.svengreb.de)
- Solarized terminal colours: microsoft/vscode (extensions/theme-solarized-*, commit d95ade0),
  from Solarized by Ethan Schoonover (altercation/solarized)
  Copyright (c) 2015 - present Microsoft Corporation
  Copyright (c) 2011 Ethan Schoonover
- Rosé Pine and Rosé Pine Dawn terminal colours: rose-pine/alacritty (dist/, commit a6f7c82)
  Copyright (c) Rosé Pine
- Gruvbox Light palette and Gruvbox terminal colours: morhetz/gruvbox (colors/gruvbox.vim,
  commit ef8864b) and morhetz/gruvbox-contrib (xresources/, commit 150e9ca), MIT/X11 as their
  README states
  Copyright (c) Pavel Pertsev (morhetz)

Tokyo Night Day's palette and the Tokyo Night terminal colours come from folke/tokyonight.nvim
(extras/, commit cdc07ac), Copyright (c) Folke Lemaitre, under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0).

The other variants' seed colours come from antigem (https://github.com/Santoshkurmi/antigem,
commit 2a04d61), Copyright (C) 2026 Santosh Kurmi, under the GNU General Public License v3.0,
as iCode itself is.
